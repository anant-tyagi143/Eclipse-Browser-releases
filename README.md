## Why Eclipse?

- **Tracker blocking** built in. Toggle it from the toolbar, and see how many trackers were stopped on each tab.
- **Private tabs** that never record history.
- **Your history stays local.** It's saved on your computer, never sent anywhere.
- **Choose your search engine** from DuckDuckGo, Brave Search, Startpage, Qwant, Mojeek, and more.
- **Four themes**: Cyber, Matrix, Amber, and Paper.
- **Automatic updates.** Eclipse checks for new versions when it starts.

## Install

1. Open the [latest release](https://github.com/anant-tyagi143/Eclipse-Browser-releases/releases/latest).
2. Download `Eclipse-Setup-x.y.z.exe`.
3. Run the installer and follow the prompts.

Need an older version? See [all releases](https://github.com/anant-tyagi143/Eclipse-Browser-releases/releases).

## Requirements

- Windows 10 or 11, 64-bit

## Good to know

- Windows may warn that the app is from an unknown publisher, because the installer isn't code-signed yet. Choose **More info > Run anyway** if you trust this download.
- Updates keep your settings and history.
