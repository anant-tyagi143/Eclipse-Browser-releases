# Eclipse

Eclipse is a privacy-first browser for Windows.

## Download

**[Download the latest version](https://github.com/anant-tyagi143/Eclipse-Browser-releases/releases/latest)**

Open the latest release and download the file named `Eclipse-Setup-x.y.z.exe`, then run it to install.

Eclipse checks for updates automatically when it starts. You can also download any earlier version from the [all releases page](https://github.com/anant-tyagi143/Eclipse-Browser-releases/releases).

## Requirements

- Windows 10 or 11 (64-bit)

## Notes

- Windows may show a warning because the installer is not code-signed yet. Choose **More info > Run anyway** if you trust the download.
- Your settings and history are kept when you update.
